# 체크 버튼 이펙트 개선 디자인

## 개요

디스플레이 페이지의 체크 버튼(✓)에 힌트 문구와 화려한 클릭 이펙트를 추가하여 "누르는 맛"을 극대화한다.

## 1. 힌트 문구

- **문구**: `👀 읽어보셨다면… 체크 한번 해보실래요?`
- **위치**: 체크 버튼 오른쪽, 같은 줄
- **스타일**: 12px(0.75vw), `#94a3b8` 색상, 👀 이모지는 `#a78bfa`

## 2. 클릭 이펙트 시스템

### 2-1. 가중치 랜덤 스케일

누를 때마다 랜덤 스케일이 뽑히며, 모든 이펙트 파라미터가 이 스케일에 비례한다.

| 등급 | 스케일 범위 | 확률 | 쿨다운 |
|------|------------|------|--------|
| 💫 초소형 | 0.04 ~ 0.12 | **85%** | 없음 (연타 가능) |
| 💥 중형 | 0.35 ~ 0.60 | **3.75%** | 1.2초 |
| 🔥 대형 | 0.65 ~ 1.00 | **3.75%** | 2초 |
| ☢️ 초대형 | 1.05 ~ 1.40 | **3.75%** | 3초 |
| 🌋 핵폭발 | 1.40 ~ 1.70 | **3.75%** | 4초 |

- 중형 이상 합산 15%: 약 7~8번 연타(~2초)에 1번 걸림
- 중형 이상 내에서는 균등 확률 (각 3.75%)
- 쿨다운 중에는 버튼 비활성화 (opacity 0.5, pointer-events none)

### 2-2. 초소형 이펙트 (버튼 주위만)

- 버튼 중심에서 반경 15~35px 내에 미니 파티클 4~6개
- 파티클: 2~5px 원형, 랜덤 컬러, 글로우
- 미니 글로우: 24px 라디얼 그라디언트 (시안)
- 지속시간: 180~330ms (매우 빠르게 사라짐)

### 2-3. 중형 이상 이펙트 (스케일 비례)

모든 파라미터가 스케일에 비례하여 자연스럽게 스케일링된다.

**버튼 글로우 플래시:**
- 버튼 자체가 시안 글로우로 빛나며 살짝 커졌다 돌아옴
- scale(1.15) → scale(1.0), box-shadow 60px 글로우

**화면 플래시:**
- 백색 플래시 (0.3 이상): opacity `0.2 + scale * 0.3`, 지속 `150 + scale * 100`ms
- 시안 플래시 (0.5 이상): 80ms 후 추가 플래시

**화면 흔들림:**
- 강도: `scale * 8`px, 지속: `200 + scale * 200`ms

**바운스 링 (Canvas):**
- 3중 링: 시안 / 퍼플 / 블루, 시차 발사
- 버튼 중심에서 확장 → 화면 벽에 닿으면 역방향 수축 (바운스)
- 벽 도달 시: 가장자리 글로우 + 작은 흔들림
- 링 크기: `화면대각선 * scale`에 비례

**중심 글로우:**
- 라디얼 그라디언트 (시안 → 퍼플 → 투명)
- 크기: `40 + scale * 150`px, blur: `6 + scale * 15`px
- scale(0) → scale(1.5 + scale * 2)로 확장하며 페이드아웃

**컨페티 폭발:**
- 개수: `6 + scale * 50`개
- 버튼 중심에서 사방으로 발사
- 크기: `3~9 + scale * 4`px 직사각형
- 중력 바이어스 적용 (아래로 치우침)
- 랜덤 회전: ±720도

**스파클 (0.5 이상):**
- 개수: `5 + scale * 20`개
- ✦ / ✧ 문자, 랜덤 컬러 + 글로우
- 0에서 커졌다가 다시 사라지는 3단 애니메이션

**컨페티 비 (0.9 이상, 초대형/핵폭발):**
- 개수: `scale * 30`개
- 화면 상단에서 아래로 떨어지는 색종이
- 좌우 흔들림 + 회전
- 300ms 딜레이 후 시작, 2~4초에 걸쳐 떨어짐

## 3. 구현 위치

- `src/app/display/page.tsx`의 `CheckButton` 컴포넌트 수정
- 이펙트 로직은 같은 파일 내 인라인 또는 별도 유틸로 분리
- 외부 라이브러리 없이 Web Animations API + Canvas로 구현

## 4. 기존 동작 유지

- 카운트 증가 (optimistic update + DB transact) — 기존 로직 그대로
- `onInteraction` 콜백 호출 — 기존 로직 그대로
- 쿨다운 중에도 카운트는 증가시키되, 이펙트만 잠금 → **아니요, 버튼 자체가 잠기므로 카운트도 안 올라감**
