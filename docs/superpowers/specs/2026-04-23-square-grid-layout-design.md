# 1:1 정사각형 2×2 그리드 레이아웃 개편

## 배경

사이니지 디스플레이 영역이 기존 16:9 가로 전체 화면에서 **1:1 정사각형 영역**으로 변경됨. 모니터를 반으로 나눠 다른 용도와 함께 사용하는 환경. 기존 60%/40% 좌우 2패널 레이아웃은 이 비율에 맞지 않아 전면 개편 필요.

## 대상 화면

- 복도 대형 사이니지 (변경 없음)
- 디스플레이 영역만 1:1 정사각형으로 변경
- 터치 인터랙션 유지

## 레이아웃 구조

### 기본 상태: 2×2 그리드

```
┌──────────────────────────────────┐
│ ● 게임소프트웨어학과 공지사항  14:30 │ ← TopBar
├────────────────┬─────────────────┤
│                │                 │
│  [1학년 공지]  │  [2학년 공지]   │
│  카테고리      │  카테고리       │
│  제목          │  제목           │
│  요약          │  요약           │
│  시간          │  시간           │
│                │                 │
├────────────────┼─────────────────┤
│                │                 │
│  [3학년 공지]  │  [4학년 공지]   │
│  카테고리      │  카테고리       │
│  제목          │  제목           │
│  요약          │  요약           │
│  시간          │  시간           │
│                │                 │
└────────────────┴─────────────────┘
         ●● ○○  ← 페이지 인디케이터
```

- `display: grid; grid-template-columns: 1fr 1fr; grid-template-rows: 1fr 1fr;`
- gap: 그리드 간격 유지
- 각 타일: 카테고리 컬러 왼쪽 바 + 배지, 제목, 요약 텍스트, 시간
- 하단에 pill 형태 페이지 인디케이터

### 타일 구성

각 타일에 표시되는 정보:
- 카테고리 컬러 좌측 바 (3px)
- 카테고리 배지 (기존 스타일 유지)
- 공지 제목 (bold)
- 본문 요약 (1-2줄, 말줄임)
- 작성 시간 (relative time)
- 체크 카운트 (작게)

### 확대 상태: 오버레이 풀스크린

```
┌──────────────────────────────────┐
│ ● 게임소프트웨어학과 공지사항  14:30 │ ← TopBar (유지)
├──────────────────────────────[X]─┤
│ ┊        ┊                       │
│ ┊........┊  2학년                │  ← 뒤에 그리드 테두리 비침
│ ┊        ┊                       │
│ ┊........┊  캡스톤 디자인 팀 배정 │
│ ┊        ┊                       │
│            본문 내용...           │
│            본문 내용...           │
│                                  │
│            ┌──────────────────┐  │
│            │ 🔗 링크 카드     │  │
│            └──────────────────┘  │
│                                  │
│          [ 👀 읽었어요 ✓ 12 ]   │
│                                  │
└──────────────────────────────────┘
         ●● ○○  ← 페이지 인디케이터
```

- 선택한 타일이 **원래 그리드 위치에서 풀스크린으로 확장** (Framer Motion `layoutId` + spring)
- 나머지 타일: 내용 fade out, **테두리만 dimmed 상태로 뒤에 남음** (opacity ~0.3)
- 확장 타일에 상세 정보 전부 표시: 본문 전체, 링크 카드, 체크 버튼
- **우상단 X 닫기 버튼**: 원형, 반투명 배경 + backdrop-blur, 눈에 띄게

## 타이머 시스템

두 개의 독립적인 타이머가 동작한다.

### 1. 페이지 순환 타이머

- **그리드 상태에서만** 카운트
- 10초마다 다음 4개 공지 페이지로 전환
- 풀스크린 상태 진입 시 → **일시정지**
- 그리드 복귀 시 → **재개** (남은 시간부터 이어서)
- 전환 애니메이션: `AnimatePresence`로 페이지 단위 fade+slide

### 2. 풀스크린 복귀 타이머

- 풀스크린 진입 시 **60초** 시작
- 내부 조작 (체크 버튼, 스크롤, 링크 터치) → **60초로 리셋**
- 60초 무조작 → **그리드로 복귀** (spring 축소 애니메이션)
- X 버튼 터치 → **즉시 그리드 복귀**

### 타이머 흐름

```
그리드 ● ─── 타일 터치 ──→ 풀스크린 ● ─── 60초 무조작 ──→ 그리드 ●
(페이지 타이머 작동)         (페이지 타이머 일시정지)        (페이지 타이머 재개)
                             (복귀 타이머 60초 시작)
                             (조작 시 복귀 타이머 리셋)
```

## 페이지네이션

- 공지를 4개씩 묶어 페이지 단위로 표시
- 공지가 4개 이하면 인디케이터 숨김
- 인디케이터: pill 형태, 현재 페이지는 넓은 bar, 나머지는 작은 dot
- 페이지 전환: `AnimatePresence` fade+slide

## 애니메이션

### 타일 확대

1. 터치한 타일: `layoutId`를 이용해 원래 그리드 위치에서 풀스크린 위치로 spring 전환
2. 나머지 타일: 내용 opacity → 0 fade out (200ms), 테두리는 opacity 0.3으로 유지
3. 확대 타일에 glow shadow 추가 (카테고리 컬러 기반)
4. 상세 내용(본문, 링크, 체크 버튼) stagger fade-in

### 타일 축소 (복귀)

1. 확대 타일: spring으로 원래 그리드 위치로 축소
2. 나머지 타일: 내용 fade-in, opacity → 1
3. 상세 내용은 축소 시작과 동시에 fade-out

### Spring 설정

기존 프로젝트의 spring 물리 유지: `damping: 25, stiffness: 200`

## 기존 기능 유지

- TopBar: 라이브 인디케이터, 브랜드 텍스트, 시계 — 그대로 유지
- 체크 버튼 + 폭발 이펙트: 풀스크린 상태에서 동작
- 북마크 카드 (링크 iframe): 풀스크린 상태에서 표시
- 카테고리 컬러 시스템: 그대로 유지
- Admin 페이지: 변경 없음

## 기술 구현 방향

- 기존 `display/page.tsx`의 2패널 구조를 2×2 그리드로 교체
- `aspect-ratio: 1` 컨테이너로 1:1 비율 강제
- Framer Motion `layoutId`, `AnimatePresence`, `motion.div` 활용
- 타이머 로직은 `useRef` + `useEffect`로 관리
- 뷰포트 상대 단위(vw/vh) 대신 그리드 컨테이너 기준 상대 단위 사용 검토
