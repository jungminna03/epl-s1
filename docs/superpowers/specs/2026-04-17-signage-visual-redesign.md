# 사이니지 비주얼 리디자인 스펙

## 개요

캠퍼스 공지사항 사이니지(display 페이지)의 비주얼을 전면 리디자인한다. 호서게임전시관 스타일의 딥 네이비 + 시안 액센트 컬러를 적용하고, 40인치+ 대형 터치스크린 디스플레이에 최적화된 레이아웃으로 변경한다.

### 레이아웃

기존 "긴급 섹션 + 일반 그리드" 단일 스크롤 레이아웃에서 **2패널 고정 레이아웃**으로 변경한다.

```
┌──────────────────────────────────────────────────┐
│  [로고][●] 게임소프트웨어학과 공지사항  2026.04.17 14:32 │  ← 상단 바
├───────────────────┬──────────────────────────────┤
│                   │  공지 목록        ● ● ○ ○   │
│   🚨 긴급         │ ┌──────────────────────────┐ │
│                   │ │ 긴급  내일 전체 학과 회의  ◂│ │  ← active
│   내일 전체       │ ├──────────────────────────┤ │
│   학과 회의 안내   │ │ 휴강  4/18 데이터베이스    ◂│ │
│                   │ ├──────────────────────────┤ │
│   4월 18일 오후 2시│ │ 일반  도서관 운영시간 변경  ◂│ │
│   본관 301호...   │ ├──────────────────────────┤ │
│                   │ │ 일반  캡스톤 디자인 중간발표 ◂│ │
│   2분 전 · 김교수  │ └──────────────────────────┘ │
│        40%        │            60%               │
└───────────────────┴──────────────────────────────┘
```

- **비율**: 좌 40% / 우 60%
- **좌측 (상세 패널)**: 선택된 공지의 카테고리 배지, 제목, 본문, 작성자/시간 표시. 카테고리에 따라 배경에 은은한 radial gradient 글로우 적용.
- **우측 (목록 패널)**: 공지 4개를 세로로 균등 배치. 각 카드는 flex:1로 패널 높이를 꽉 채움. 카테고리 컬러바(좌측 4px) + 배지 + 제목 + 메타 정보.
- **상단 바**: 학과 로고 아이콘 + "게임소프트웨어학과 공지사항" (좌), 날짜 + 시계 (우). 시계는 44px. 로고는 `public/logo.png`에 배치 (흑백 기하학 로고, 디스플레이에서는 반전/밝은 색으로 표시).
- **스크롤 없음**: 100vh 고정, overflow:hidden.

### 인터랙션

#### 자동 순환
- 5초 간격으로 다음 공지로 자동 전환
- 활성 카드 하단에 프로그레스바(2px)가 좌→우로 채워지며 남은 시간 표시
- 프로그레스바 색상은 카테고리 컬러의 40% 투명도
- 상단 우측에 순환 인디케이터 (dot 4개, 활성 dot은 가로로 길어짐)

#### 터치 선택
- 우측 목록의 공지를 터치하면 좌측에 해당 공지 상세 표시
- 터치 시 자동 순환 타이머 리셋 (다시 5초부터 시작)
- 상세 패널 전환 시 fadeIn + translateY 애니메이션 (0.45s ease)

#### 호버 효과
- 적용하지 않음 (터치스크린 전용)

### 애니메이션

#### 카드 진입 (페이지 로드/공지 추가)
- `translateX(-20px) → translateX(0)` + `opacity: 0 → 1`
- `cubic-bezier(0.34, 1.56, 0.64, 1)` (바운스 느낌)
- 각 카드 0.1s 간격으로 stagger (0.1s, 0.2s, 0.3s, 0.4s)
- Framer Motion `AnimatePresence` + `motion.div`로 구현

#### 긴급 공지 효과
- 긴급 카드가 활성일 때 좌측 패널 배경에 radial gradient 글로우가 은은하게 pulse
- 별도의 flash나 과한 효과 없이 배경 글로우만으로 차별화

#### 라이브 인디케이터
- 시안 dot에 `box-shadow` 글로우 pulse (2s 주기)

#### 상세 패널 전환
- `opacity: 0, translateY: 16px → opacity: 1, translateY: 0` (0.45s ease)
- 공지 전환 시마다 재생

### 공지가 4개 미만일 때

- 카드가 1~3개여도 flex:1로 균등 배치하여 높이를 채움
- 공지가 0개일 때는 우측 패널에 빈 상태 메시지, 좌측 패널도 빈 상태

### 공지가 4개 초과일 때

- 최근 4개만 표시하고 자동 순환
- 순환이 한 바퀴 돌면 다음 4개 세트로 전환 (페이지네이션)
- 순환 인디케이터 dot 수는 현재 세트의 공지 수에 맞춤

### 반응형 (admin 등 다른 기기에서 접근 시)

- display 페이지는 대형 디스플레이 전용이므로 모바일 반응형은 고려하지 않음
- admin 페이지는 기존 스타일 유지 (별도 작업)
- 단, globals.css의 테마 토큰(배경, 전경, 폰트)은 공유하므로 admin에도 컬러 변경이 반영됨
