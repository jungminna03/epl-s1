# NoticeWidget - 공지사항 위젯 앱

## 프로젝트 개요

EPL-S1 (https://epl-s1.vercel.app/display) 캠퍼스 공지사항 시스템과 연동하는 Windows 데스크톱 위젯 애플리케이션

---

## 🎯 핵심 요구사항

### 1. 외부 연동 - EPL-S1 공지사항 API

| 항목 | 내용 |
|:---|:---|
| **연동 대상** | https://epl-s1.vercel.app/display |
| **API 엔드포인트** | `/api/notices` (백엔드 협의 필요) |
| **데이터 형식** | JSON |
| **동기화 주기** | 5분 간격 자동 새로고침 |

**공지사항 데이터 구조:**
- id: 공지 고유 ID
- type: 공지 분류
- title: 제목
- content: 내용
- date: 등록일
- duration: 노출 기간 (null = 무제한, 단위: 일)
- unlimited: 기간 제한 없음 여부 (boolean)

### 4. 헤더 영역 (Header)

**높이:** 50px  
**배경:** `--bg-window`와 동일하거나 약간 진한 `#888888`  
**레이아웃:** Flexbox, `justify-content: space-between`, `align-items: center`  
**패딩:** 좌우 8px, 상하 4px

#### 좌측: 버전 표시
- **형식:** `V.{년}.{월}.{업데이트순번}`
- **예시:** `V.2026.5.1`
- **폰트:** 11px, Regular, `--text-muted`
- **위치:** 헤더 좌측 상단 정렬

#### 중앙: 학과 / 부서 정보
- **구성:** `📢 {학과명} 공지 사항`
- **예시:** `📢 게임소프트웨어학과 공지 사항`
- **폰트:** 13px
  - 학과명: Bold, 하늘색 계열 강조 (`--accent-notice`)
  - "공지 사항": Regular, `--text-secondary`
- **위치:** 헤더 중앙 또는 좌측 버전 옆 자연스럽게 배치

#### 우측: 날짜 및 시간
- **날짜 형식:** `YYYY/MM/DD (요일)`
  - 예시: `2026/05/11 (월)`
  - 폰트: 12px, Regular, `--text-secondary`
- **시간 형식:** `HH:mm` (24시간제)
  - 예시: `02:50`
  - 폰트: 24px, Bold, `--text-primary`
- **위치:** 헤더 우측 정렬, 세로로 날짜(위)-시간(아래) 배치

#### 닫기 버튼 (개발 모드만)
- **위치:** 버전 표시 왼쪽 또는 별도의 우측 상단
- **표시 조건:** `isDebug === true` 일 때만 노출
- **스타일:** 14px, `--text-muted`, hover 시 `--text-primary`

#### 맨 뒤로 보내기 버튼 (배포/릴리스 모드)
- **위치:** 헤더 우측, 날짜/시간 옆
- **표시 조건:** `isDebug === false` (배포 모드) 일 때만 노출
- **아이콘:** 🔽 또는 🗕 (맨 뒤로 가기 아이콘)
- **스타일:** 14px, `--text-muted`, hover 시 `--text-primary`
- **동작:** 클릭 시 위젯 창을 `SetWindowPos(HWND_BOTTOM)`로 맨 뒤로 보냄
- **목적:** 위젯이 맨 앞으로 왔을 때 사용자가 수동으로 뒤로 보낼 수 있게 함
- **개발 모드:** 버튼 없음 (개발 시에는 창이 계속 맨 위에 있음)

### 5. 공지 카드 리스트 (Notice Cards)

#### 5.1 레이아웃 방식 - 고정 크기 카드

| 항목 | 내용 |
|:---|:---|
| **배경** | `--bg-window` (`#999999`) |
| **패딩** | 8px (좌우 8px, 상하 8px) |
| **간격** | 카드 간 8px (`gap: 8px`) |
| **카드 높이** | **고정 100px** - 모든 카드 동일한 크기 |
| **표시 방식** | **페이지당 4개 고정**, 총 **3페이지** (최대 12개 공지 표시) |

#### 5.2 페이지 자동 순환 (Auto Pagination)

| 설정 | 값 |
|:---|:---|
| **총 페이지 수** | **3페이지 고정** (추가 페이지 없음) |
| **페이지당 카드 수** | **4개 고정** |
| **총 표시 공지 수** | **최대 12개** (공지 13개 이상은 표시하지 않음) |
| **한 페이지 표시 시간** | 10초 |
| **전환 방식** | **세로 슬라이드 업** (위로 밀려 올라감) |
| **전환 시간** | 0.45초 |
| **루프** | 3페이지 → 1페이지로 순환 |

**동작 예시:**
- 공지 4개 이하: 1페이지만 표시, 인디케이터 없음
- 공지 8개: 1페이지(4개) → 10초 후 → 2페이지(4개) → 루프
- 공지 12개: 1→2→3페이지 순환
- 공지 15개: **최신 12개만 표시**, 나머지 3개는 표시하지 않음

#### 5.3 개별 카드 스타일
- **배경:** `--bg-card` (`#555555`)
- **높이:** **고정 100px** (모든 카드 동일)
- **모서리:** `border-radius: 6px`
- **패딩:** 16px
- **그림자:** 없음 (플랫 디자인)
- **특징:** 화면에 꽉 차지 않아도 됨, 여백 있을 수 있음

#### 5.4 카드 내부 텍스트
- **제목:** 22px, Bold, `#FFFFFF`
  - 한 줄 또는 두 줄까지 표시, 초과 시 말줄임표(`…`)
- **정렬:** 좌측 정렬, 세로 중앙 정렬

#### 5.5 카드 인터랙션 및 확인 상태

| 상태 | 스타일 |
|:---|:---|
| **기본** | `--bg-card` (`#555555`), 커서: pointer |
| **Hover** | 밝기 10% 상승 (약 `#666666`) |
| **미확인 공지 (New)** | 우측에 **빨간 동그라미 배지** 표시 |
| **확인 완료** | 빨간 동그라미 없음, 평소 상태 |

#### 5.6 확인 상태 관리 (전체 일괄 갱신)

| 설정 | 값 |
|:---|:---|
| **표시 위치** | 카드 우측 |
| **배지 스타일** | 빨간색 원형 (`#FF4444`, 12px), 애니메이션 (pulse) |
| **확인 처리** | 카드 클릭 → 상세 보기 → "확인했어요" 버튼 클릭 |
| **갱신 방식** | **전체 일괄 타이머** - 어떤 공지를 확인하든 전체 타이머가 갱신됨 |
| **재표시 조건** | **매 정각** (1:00, 2:00, 3:00...) 및 **부팅 직후** 모든 공지에 빨간 동그라미 재표시 |
| **재표시 시 동작** | 위젯 창을 **맨 앞으로 가져와** 사용자에게 알림 |
| **전체 미확인 수** | 헤더 학과명 옆에 배지로 표시 |

**동작 예시:**
1. **부팅 직후** → 모든 공지에 빨간 동그라미 + **위젯 창 맨 앞 노출**
2. **1:00** → 모든 공지 빨간 동그라미 재표시 + **위젯 창 맨 앞으로**
3. 사용자가 공지 확인 → 동그라미 사라짐
4. **맨 뒤로 보내기**는 사용자가 **반드시 버튼을 눌러야 함** (자동 이동 없음)

**창 제어 방식 선택 (택일):**
- **A. 버튼 방식:** 헤더에 "맨 뒤로 보내기" 버튼 표시, 사용자가 수동 클릭
- **B. 창 클릭 방식:** 위젯 창을 클릭하면 자동으로 맨 앞으로 옴 (이미 다른 창 뒤에 있을 때)
4. **2:00** → 다시 빨간 동그라미 + **위젯 창 맨 앞으로** (반복)

#### 5.7 헤더 미확인 카운트 배지
| 항목 | 내용 |

| **위치** | "공지 사항" 텍스트 우측 |

#### 5.6 페이지 인디케이터 (하단)
| 항목 | 내용 |
|:---|:---|
| **표시 조건** | 페이지 수 > 1일 때만 표시 |

| **스타일** | 도트 형태 (현재 페이지: 하늘색, 나머지: 어둡게) |

### 6. 공지사항 노출 기간 관리

#### 기본 동작
- **기간 미설정 공지:** 업로드 후 7일(일주일)간 노출 → 이후 자동 삭제

#### 업로드 옵션 (백엔드에서 설정)
| 옵션 | 동작 |
|:---|:---|
| `duration={일수}` | 해당 일수만큼 노출 후 삭제 |
| `unlimited=true` | 기간 제한 없음, 영구 노출 |
| 미설정 (default) | 7일 후 자동 삭제 |

**클라이언트 처리:**
- 로컬에서 `date + duration` 계산하여 만료된 공지 필터링
- 만료 임박 공지는 시각적으로 표시 (예: 테두리 노란색)

### 7. 공지 상세 보기 - 확장형 오버레이 (Expanding Overlay)

#### 인터랙션 방식

| 요소 | 설명 |
|:---|:---|
| **트리거** | 공지 리스트의 특정 항목 클릭 시 발생 |
| **모션** | 클릭한 리스트 아이템이 중앙으로 커지면서 상세 팝업으로 전환 (공유 요소 전이/Shared Element Transition) |
| **배경** | 딤드 (Dimmed, 불투명도 60~70%) 처리하여 상세 내용에 집중 |

#### 상세 구성 요소 및 제어

| UI 요소 | 위치 | 동작 |
|:---|:---|:---|
| **닫기(X) 버튼** | 팝업 우측 상단 | 클릭 시 팝업 닫힘 |
| **Dimmed 영역 클릭** | 팝업 외곽 | 클릭 시 팝업 닫힘 (Dismiss) |
| **확인 버튼** | 팝업 하단 | "확인했어요" 버튼 (읽음 처리 연동) |

#### 예외 케이스 처리

| 케이스 | 처리 방식 |
|:---|:---|
| **내용 길이 초과** | 팝업 내부에서 개별 스크롤 (Internal Scroll) 동작 |
| **닫기 애니메이션** | 원래 리스트 위치로 작아지며 사라지는 역재생 애니메이션 적용 |

### 8. 창 제어 (개발 vs 배포)

#### 개발/디버그 모드
| 기능 | 동작 |
|:---|:---|
| 닫기 버튼 (✕) | ✅ 활성화 - 프로그램 종료 |
| Alt+F4 | ✅ 활성화 - 프로그램 종료 |
| 작업 관리자 종료 | ✅ 가능 |
| 창 이동 | ✅ 드래그로 이동 가능 |
| 창 크기 조절 | ✅ 가능 |
| 기능 | 동작 |
|:---|:---|
| 닫기 버튼 | ❌ **숨김 또는 비활성화** |
| Alt+F4 | ❌ **차단** |
| 작업 관리자 종료 | ❌ **Watchdog으로 자동 복구** |
| 창 이동 | ❌ **고정** (마우스 드래그 무시) |
| 창 크기 조절 | ❌ **400×600px 고정** |
| **Z-Order (창 순서)** | ❌ **항상 위 고정 안 함**. 다른 창 뒤로 가려질 수 있음 |
| **창 가시성** | ❌ **창을 키우면 화면에서 안 보이도록** (작업 표시줄 미표시, 배경처럼 동작) |
| **맨 뒤로 보내기** | 🔽 **헤더에 버튼 추가** - 사용자가 원할 때 위젯을 뒤로 보낼 수 있음 |

**모드 전환:** 빌드 설정 또는 `config.json`의 `isDebug` 플래그로 제어

### 10. 자동 실행 및 복구

#### 배포 모드 전용
| 기능 | 설명 |
|:---|:---|
| **시작 프로그램 등록** | Windows 로그인 시 자동 실행 |
| **Watchdog 모니터링** | 5초 간격으로 프로세스 상태 확인 |
| **자동 복구** | 종료/충돌 시 즉시 재실행 |
| **창 표시 동작** | 다른 창 클릭 시 뒤로 가려짐. `SetWindowPos(HWND_BOTTOM)` 또는 `WS_EX_NOACTIVATE` 적용. 사용자가 직접 창을 키워도(클릭/포커스) 앞으로 나오지 않음 |
